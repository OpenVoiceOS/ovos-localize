# Repositories OVOS Localize can open a pull request against.
#
# Only repositories owned by OpenVoiceOS, TigreGotico and JarbasHiveMind can
# appear here. Submitting a translation ends with a GitHub App asking for an
# installation token scoped to the target repository, and that call returns
# 404 wherever the app is not installed -- which no third-party owner can be
# asked to allow on our behalf. A repository outside these orgs therefore
# collects translations that can never be delivered.
#
# Maintainers of skills elsewhere: fork this repository and run it yourself.
# It is a static site plus GitHub Actions with no server of any kind, so
# pointing your own fork at your own repositories costs you nothing but the
# fork. See FAQ.md.
